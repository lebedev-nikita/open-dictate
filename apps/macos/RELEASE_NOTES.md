OpenDictate for macOS **0.5.0-rc.27** simplifies the keyboard shortcuts page. Requires macOS 14+ on Apple Silicon or Intel.

- Shortcut actions use compact, consistently spaced rows with aligned key labels. The fixed Escape reference follows the editable shortcuts, and Restore default shortcuts sits below the list.
- Redundant guidance and the lower help sections have been removed. Voice-editing guidance is available from the information button beside its label.
- Switching back to System theme now updates the application appearance correctly.

Download the universal DMG and replace OpenDictate in Applications. This release candidate is ad-hoc signed and **not notarized**. Verify the attached SHA-256 checksum.
