# OpenDictate for macOS 0.5.0-rc.1

- View and edit the transcription prompt in Dictation settings. Save a custom prompt, send no prompt with an empty text, or reset to the built-in default.
- Share custom prompts and explicit resets between Android and macOS through optional Google Drive synchronization. Untouched built-in prompts are never uploaded.
- Apply the prompt to Live, Accurate and retranscription while keeping languages and dictionary terms separate. Changes apply to the next session.

After synchronizing a reset, older apps pause Drive sync until updated to a version that supports nullable prompt values. Update both platforms before testing cross-device resets.

This release candidate is ad-hoc signed and not notarized by Apple. See INSTALL.txt in the disk image for Gatekeeper instructions.
